# ボードゲーム箱

五目並べ・リバーシ・チェス・将棋・囲碁を、ひとつのアプリにまとめたスマホ向けの Web アプリ（PWA）です。
ブラウザで開いて「ホーム画面に追加」すれば、普通のアプリと同じように起動でき、オフラインでも遊べます。

## できること

- **2人対戦**：同じ端末で交互に指す
- **CPU対戦**：強さは3段階（弱い／普通／強い）。先手・後手を選べる
- **待った・投了・盤面反転**（反転はチェス・将棋のみ）
- **対局の自動保存**：アプリを閉じても続きから遊べる
- CPU は Web Worker で考えるため、思考中も画面は固まりません

各ゲームは公式ルールに沿って実装しています。大会や団体によってルールが分かれるものは、「新しい対局」で選べます。

| ゲーム | 準拠するルール | 主な内容 | 選べるもの |
|---|---|---|---|
| 五目並べ | 自由／標準／連珠 | 連珠では黒の三三・四四・長連を判定（五が優先、四三は可） | 開局規定：Swap・Swap2（五目並べ）、旧RIF・山口・Soosõrv-8・Taraguchi-10（連珠） |
| リバーシ | 日本オセロ連盟の競技ルール | 自動パス、空きマスは勝者に加算 | ― |
| チェス | FIDE チェス規則 | キャスリング、アンパッサン、昇格、ステイルメイト、デッドポジション、5回同形・75手は自動、合意による引き分け、時間切れ時の駒不足判定 | 3回同形・50手：申請制（FIDE）／自動 |
| 将棋 | 日本将棋連盟の対局規定 | 二歩、打ち歩詰め、行き所のない駒、千日手（連続王手は反則負け）、合意による持将棋 | 入玉宣言：27点法／24点法、駒落ち（香落ち〜八枚落ち） |
| 囲碁 | 日本囲碁規約／中国ルール／AGAルール | コウ、自殺手の禁止、死石の確認、セキ、同形反復（無勝負または超コウ） | ルール、コミ、互先・定先・置き碁、盤の大きさ |

**持ち時間**は全ゲーム共通で、なし・切れ負け・秒読み（回数あり）・フィッシャー・カナダ式・遅延から選べます。ゲームごとによく使われる設定はプリセットになっています。

スマホでの誤タップを防ぐため、囲碁と五目並べでは**同じ場所を2回タップすると着手が確定**します。

## ルールブックと初心者ガイド

メニューの「ルール」ボタン、または対局画面右上の「？」から、各ゲームの説明を読めます。

- **はじめての人へ**：目的・駒や石の動かし方・基本の形・上達のコツを、図を使って説明
- **ルールブック**：公式ルールにもとづく細かい規定と、このアプリでの扱い

ガイドの図のうち、ルール判定に関わるもの（五目並べの禁じ手、将棋の打ち歩詰めなど）は、実際のルール判定と一致することをテストで確認しています。

## 公開（GitHub Pages）

`main` ブランチに push すると、GitHub Actions がテストとビルドを行い、GitHub Pages に公開します。
初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開先は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## 開発

```sh
npm install
npm run dev        # 開発サーバー
npm test           # ルールエンジンのテスト
npm run build      # 型チェック + 本番ビルド（dist/ に出力）
npm run preview    # ビルド結果の確認
```

`dist/` を任意の静的ホスティング（GitHub Pages、Netlify、Cloudflare Pages など）に置けば公開できます。
相対パスでビルドしているので、サブディレクトリに置いても動きます。

## 構成

```
src/
  core/          共通の型、対局セッション管理（待った・保存・CPU呼び出し）、CPU用 Web Worker
  components/    共通の画面部品（ヘッダー、設定シート、交点の盤）
  games/<名前>/  engine.ts（ルールと CPU）と画面コンポーネント
public/          manifest、Service Worker、アイコン
```

ゲームを追加するときは、`GameEngine` を実装した `engine.ts` と画面を作り、
`src/App.tsx` の一覧と `src/core/ai.worker.ts` に登録します。
