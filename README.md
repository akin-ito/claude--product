# ボードゲーム箱

五目並べ・オセロ・チェス・将棋・囲碁を、ひとつのアプリにまとめたスマホ向けの Web アプリ（PWA）です。
ブラウザで開いて「ホーム画面に追加」すれば、普通のアプリと同じように起動でき、オフラインでも遊べます。

## できること

- **2人対戦**：同じ端末で交互に指す
- **CPU対戦**：強さは3段階（弱い／普通／強い）。先手・後手を選べる
- **待った・投了・盤面反転**（反転はチェス・将棋のみ）
- **対局の自動保存**：アプリを閉じても続きから遊べる
- CPU は Web Worker で考えるため、思考中も画面は固まりません

| ゲーム | 実装しているルール |
|---|---|
| 五目並べ | 15路盤。5つ以上並べたら勝ち（自由ルール） |
| オセロ | 打てる場所がなければ自動でパス。両者打てなければ終局 |
| チェス | キャスリング、アンパッサン、昇格、チェックメイト／ステイルメイト、同一局面3回・50手ルール・駒不足による引き分け |
| 将棋 | 持ち駒、成り（強制成りを含む）、二歩、打ち歩詰め、行き所のない駒の禁止、千日手（連続王手の千日手は王手した側の負け） |
| 囲碁 | 9・13・19路。コウ、自殺手の禁止、パス2回で終局。死石は自動で推定し、タップで修正できる。日本ルールで計算（コミ6目半） |

スマホでの誤タップを防ぐため、囲碁と五目並べでは**同じ場所を2回タップすると着手が確定**します。

## 開発

```sh
npm install
npm run dev        # 開発サーバー
npm test           # ルールエンジンのテスト
npm run build      # 型チェック + 本番ビルド（dist/ に出力）
npm run preview    # ビルド結果の確認
```

`dist/` を任意の静的ホスティング（GitHub Pages、Netlify、Cloudflare Pages など）に置けば公開できます。
相対パスでビルドしているので、サブディレクトリに置いても動きます。

## 構成

```
src/
  core/          共通の型、対局セッション管理（待った・保存・CPU呼び出し）、CPU用 Web Worker
  components/    共通の画面部品（ヘッダー、設定シート、交点の盤）
  games/<名前>/  engine.ts（ルールと CPU）と画面コンポーネント
public/          manifest、Service Worker、アイコン
```

ゲームを追加するときは、`GameEngine` を実装した `engine.ts` と画面を作り、
`src/App.tsx` の一覧と `src/core/ai.worker.ts` に登録します。
